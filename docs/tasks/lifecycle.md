# Lifecycle

```
Backlog → Planned → Implementing → Tests Added → Tests Passing
  → Security Review → 5-Axis Review → QA Validation → Accepted
```

Evidence at each stage: task card, pytest log, security notes, 5-axis notes, req-ID map.

**Max 2** implementation retries after a failed gate; then ask the human.

Human approval: start of T-API-01, scoring-weight changes, privileged testbed, new major dependencies.
